# Neuronal membrane extension (experimental)

These modules extend existing MDscope rather than duplicating RMSD/RMSF,
DSSP, SASA, whole-bilayer MSD, lipid chain order or residue-to-membrane
minimum distance calculations.

## Configuration

Add under `analyses:` of your existing YAML:

```yaml
  local_environment:
    enabled: true
    protein_selection: "protein"
    anchor_selection: "protein and name CA and (resid 151-170 or resid 349-368)"
    lipid_selection: "resname POPC POPE POPI POPS DOPC DPPC PSM CHL1 CER160 CER1 BGAL GM1a"
    glycan_selection: "resname AGLCNA AIDOA BGLCA BGAL BXYL"
    ion_selection: "resname SOD NA CLA CL POT K CAL CA"
    contact_cutoff_A: 5.0
    annulus_A: 12.0
    motifs:
      nxip: "N.IP"
      tm_gxxxg: "G...G"
  lipid_diffusion:
    enabled: true
    axis: z
    max_lag_frames: 1500
    fit_start_fraction: 0.25
    fit_end_fraction: 0.75
    plots: true
  coupling_screen:
    enabled: true
    include_defaults: true
    block_frames: 50
    pairs:
      - {name: custom_lipid_rg, x: local_protein_lipid_contact_residues_count, y: radius_of_gyration_A}

statistics:
  hypothesis_tests:
    enabled: false
```

Use `python -m mdscope.analysis.cli validate <config.yaml>` then `run` / `replicate` / `finalize` as documented in README. Run each replicate separately via job arrays for large systems.

### Data and figure outputs

Each replicate:
- `extensions/local_environment/timeseries.parquet`: scalar series merged into regular `summary/timeseries.parquet` and processed by the **existing** hierarchical statistical and figure code.
- `extensions/local_environment/residue_contacts.parquet`: long-form contact counts.
- `extensions/local_environment/motifs.parquet`: discovered motif IDs.
- `extensions/lipid_diffusion/msd_by_species.parquet`: lag-dependent mean-squared displacement by lipid species, Å², ps.
- `extensions/lipid_diffusion/coefficients.parquet`: exploratory D in nm²/ns; replicate is sampling unit, not lipid or frame.
- `extensions/lipid_diffusion/diffusion_msd.png`: multi-origin MSD curves.

Project:
- `project_summary/mechanisms/replicate_correlations.parquet`: within-replicate block-mean associations.
- `project_summary/mechanisms/mechanism_consistency.parquet`: magnitude and sign reproducibility.

### Interpretive limitations

- All coupling outcomes are **exploratory correlations**, never causal discovery. Block averages do not establish sampling independence. No p-values generated by coupling screen.
- The default geometry assumes a bilayer perpendicular to z with an **orthorhombic** cell for lipid enrichment. Verify centered/whole molecules; periodic drift correction assumes displacement per analyzed step is less than half the box length.
- Lateral diffusion removes common lipid translation; use stable lag fitting windows and compare window sensitivity and trajectory segments. These are multi-origin time averages, not independent replicates. The existing membrane MSD routine is a single-origin observable and is not a species-resolved D estimate.
- Lipid enrichment measures the fraction of each species inside a radial annulus divided by the all-lipid fraction inside that annulus. It is not a potential of mean force or binding affinity. This ratio is invalid if lipids span incompatible leaflets or selection composition differs across conditions.
- Motifs match actual topology-derived amino-acid sequences, by chain. A local contact or motif accessibility proxy is **not an experimental binding assay**. Direct solvent accessibility still requires SASA with an appropriate selection, including HS occlusion.
- Protein/HS atom/residue naming depends on topology (CHARMM-GUI naming can differ); validate selections and results on a short trajectory segment.
- Work still needed: robust leaflet-specific enrichment, local order/thickness maps, water-bridge geometry, group-specific HS analysis, GXXXG crossing angles, unbiased chain symmetry, diffusion fit-window diagnostics, and full end-to-end trajectory regression tests. Do not infer these features exist from the code added here.
